# Soukbunar – serije pomaka (PWA)

Interaktivna karta Sentinel-1 PS vremenskih serija pomaka za klizište Soukbunar, Sarajevo.
Klik na tačku daje seriju vertikalnog pomaka i pomaka niz kosinu.

Status: preliminarno.

Aplikacija se može instalirati (Chrome/Edge: ikona za instalaciju u adresnoj traci; iPhone: Share → Add to Home Screen) i radi offline za već pregledane dijelove karte.
